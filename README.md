# 超级快捷键 · 各版本体验下载

同一个超级快捷键，用不同的界面技术写成的几个版本，以及配套工具 KeyCast。
它们是课程“从 0 用 Vibe Coding 开发商业级 Windows 软件：超级快捷键”里的学习项目，放在这里供大家下载体验、对比。

日常使用请下载[超级快捷键](https://github.com/superkeyapp/superkey-release/releases)，或者到[官网](https://superkeyapp.github.io)下载。

**下载**：到本页右侧的 [Releases](https://github.com/superkeyapp/superkey-demo/releases)：

| 版本 | 界面技术 | 文件 |
|---|---|---|
| 超级快捷键 (WPF) | WPF（.NET） | `SuperKey-WPF-<版本>-x64-Setup.exe` / `-Portable.zip` |
| 超级快捷键 (Electron) | Electron + React | `SuperKey-Electron-<版本>-x64-Setup.exe` / `-Portable.zip` |
| 超级快捷键 (Tauri) | Tauri + React | `SuperKey-Tauri-<版本>-x64-Setup.exe` / `-Portable.zip` |
| 超级快捷键 (Direct2D) | Direct2D 自绘（试验，未经实际使用） | `SuperKey-Direct2D-<版本>-x64-Setup.exe` / `-Portable.zip` |
| KeyCast 按键显示 | WPF（.NET） | 录屏、讲课时把按键显示在屏幕上 |

各版本用的是同一份设置，同一时间只能运行一个；装了多个版本时，先退出正在运行的那个再打开另一个。

课程介绍：[课程页面](https://superkeyapp.github.io/course/)。本仓库只放安装包，不包含源码。

本软件采用 Vibe Coding 的方式开发（由 AI 编写代码，开发者逐项测试、修改），仅供学习和研究使用，请勿用于任何非法用途。
